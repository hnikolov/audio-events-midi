# Feature: BOSS GT-100 MIDI preset support

## Summary

Support for the BOSS GT-100 as a MIDI-controlled device is added using the device’s standard fixed bank/program map.

When `SYSTEM > MIDI SETTING > MAP SELECT` is set to `FIX`, the GT-100 uses:

- `CC#0` as the bank select
- `Program Change` as the patch selector within that bank

The bank layout is:

- Bank 0: User U01-1 to U25-4
- Bank 1: User U26-1 to U50-4
- Bank 2: Factory P01-1 to P25-4
- Bank 3: Factory P26-1 to P50-4

## Behavior

The app treats the GT-100 as a supported MIDI family and dispatches preset changes as:

- `CC#0 = bank`
- `PC = programIndex`

with `programIndex` calculated as `((preset - 1) % 100)` and the bank derived from the preset slot.

This allows presets to be selected across the full GT-100 patch range without exposing bank logic in the general marker/event system.

The actual fixed mapping is:

- `bank 0, PC 0` -> `U01-1`
- `bank 0, PC 1` -> `U01-2`
- ...
- `bank 0, PC 99` -> `U25-4`
- `bank 1, PC 0` -> `U26-1`
- ...
- `bank 3, PC 99` -> `P50-4`

This matches the Roland/BOSS manuals and the standard MIDI bank-select + program-change pattern.

## Implementation notes

- Added a `gt-100` device profile and detection for GT-100 USB/BLE connections.
- Added a dedicated GT-100 route mode that translates preset numbers to the required MIDI Bank Select + Program Change sequence.
- Kept the default mode aligned with `FIX` map behavior for predictable first-party support.
- The app still handles device routing through the standard profile/route architecture, so the GT-100 fits cleanly alongside the existing supported devices.

## Scope

Initial support targets the GT-100’s fixed MIDI map and standard preset selection flow. Custom `PROG` map configuration remains out of scope for the first implementation.
